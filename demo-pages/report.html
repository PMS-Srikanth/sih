Of the sensitive things on the page, how many were caught — and of the things caught, how many were actually sensitive?

Run against a fixture carrying 12 planted secrets and 9 deliberate hard negatives (an order number, a tracking ID, a Verhoeff-invalid Aadhaar, a Luhn-invalid card) that must NOT be redacted. Recall alone is easy — redact everything. Precision is what makes it hard.

3 Precision of redaction 20% of the marks

12 changed, 8 kept measured this run

When something is removed, is only that thing removed — or the paragraph around it?

Redaction works on character offsets inside a value, not on whole elements: eleven characters of an email are replaced, not the sentence containing it. The verifier re-scans the serialised bytes afterwards and can veto transmission.

4 Client-side resource usage 20% of the marks

1 region(s) analysed measured this run

What does running this actually cost the user's laptop?

On a 20×15 grid of 32px cells, the DOM accounts for 90 of 300. Everything it cannot explain is merged into 1 region(s) — and only those are given to a model. The whole-frame alternative is one model pass over all 300 cells, every step. The extension also reports its compute backend and heap live in the side panel.

One fixture is not a benchmark. This is a small, adversarial test set we wrote ourselves; it demonstrates the method and guards against regressions, but it is not evidence of accuracy on the open web.

The verifier — the last gate before the network

The redactor decides what to remove. The verifier independently re-reads the bytes that are about to be sent and can refuse. It is deliberately not the same code, so a bug in one is not automatically a bug in the other.

CheckWhat it proves
V1 Re-scan serialised bytes clean pass
V2 Vault cross-check 10 handle(s), none leaked pass
V3 Masks verified on the bitmap no frame captured this step pass
V4 Entropy sweep clean pass
V5 Key whitelist all keys expected pass

If any check fails, transmission does not happen. The agent stops rather than sending something it cannot vouch for.
